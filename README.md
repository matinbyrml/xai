# xai
This repository contains a collection of Jupyter Notebooks demonstrating practical implementations of Explainable Artificial Intelligence (XAI) techniques. The labs progress from inherently interpretable white-box models to advanced post-hoc techniques for explaining complex black-box models (like Deep Random Forests and Gradient Boosted machines).

The primary dataset used across these labs is the Titanic Survival Dataset, providing a consistent baseline to compare how different XAI methods interpret the exact same features.
